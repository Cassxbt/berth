What is not true yet

Stated before you ask

The limits of the claim, in the same place as the claim.

Testnet only. The value is testnet value. The contracts, addresses and enforcement are the production CCTP V2 deployments.

Gas was always sponsored. The wallet has never paid for its own gas, so the self-funded path is untested.

Exclusivity is about callers, not custody. No address other than the named one can call receiveMessage for these messages, and Circle's contract enforces that. It is not a claim that the underlying Turnkey key is unreachable. We looked for a way to prove key non-exportability from outside and did not find one.

Hook delivery is two transactions. Atomic delivery is unavailable. If a mint lands and the hook then fails, nothing retries it.

Two transfers is not a corpus. The refusal path is reproducible without limit; the execution path is n=2. Nothing is claimed about throughput.
